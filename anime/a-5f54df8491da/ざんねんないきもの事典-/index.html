Synopsis

This sequel introduces creatures like pufferfish and capybaras that have acquired somewhat unfortunate characteristics during the course of evolution, using songs and fun dialogue skits. Each episode features a different animal with a surprising side that will make you want to ask, "How did that happen!?", presented in a way that can be enjoyed by both children and adults.
