Synopsis

This is the second season of a five-minute, self-contained program featuring 3DCG animation set to famous classical music and computer characters. The program consists of an opening where the computer's main unit, "Hardy," and the mouse, "Commy," introduce the music, followed by the main CG animation without dialogue, set to the atmosphere of famous pieces such as Beethoven's "Für Elise."
